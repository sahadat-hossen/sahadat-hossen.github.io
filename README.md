# Md Sahadat Hossen – Portfolio

Static portfolio site (HTML, CSS and JS in a single `index.html`, no build step).

## Publish on GitHub Pages
1. Create a repository named `<your-username>.github.io` (or any name) and push these files to the `main` branch.
2. In the repository go to **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Your site will be live at `https://<your-username>.github.io/` (or `/<repo-name>/` for other repo names) within a minute or two.

## Edit
- Projects live in the `PROJECTS` array near the bottom of `index.html`.
- Replace `assets/Sahadat_Hossen_CV.pdf` to update the downloadable CV.
